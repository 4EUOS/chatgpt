This is actually a really solid core idea because it has:

a clear “monster vs survivors” loop

progression/shop potential

tension from possession

It’s basically classic Roblox horror mixed with skill-check mechanics.

Here’s how I’d expand it into a full game so it actually feels polished and addictive instead of “just another round game.”

Core Gameplay Loop
Match Start
6–12 players load into the mansion

Intermission

Random player becomes Ghost

Hunters spawn with starter beam weapons

Ghost spawns hidden in mansion

Ghost Gameplay
The Ghost should feel:

powerful

scary

sneaky

not overpowered

Ghost Abilities
1. Possession
Main ability.

Ghost gets close to player and holds click/key for ~2 seconds.

Player enters:

darkened screen

whispers

heartbeat

distorted UI

random circles appear

If player hits circles correctly:

escape possession

ghost gets stunned briefly

If player fails:

takes major damage OR gains a “Possessed Stack”

At 3 stacks:

instant death

Cooldown:

20–30 sec per target

prevents spam

2. Phase Walk
Ghost can:

walk through SOME walls

maybe only marked walls

Cooldown ability.

Makes chase scenes terrifying.

3. Scream
AOE fear effect:

hunters blurry vision

slower movement

flashlight flickers

4. Fake Sounds
Ghost can trigger:

footsteps

doors

whispers

fake heartbeat

Psychological horror.
